# Studio Groen

Een demo-website voor een fictieve tuinontwerpstudio, gemaakt voor SD Essentials - opdracht H7.

## Openen

Open `index.html` in een webbrowser. Er is geen installatie nodig.

## Pagina's

- `index.html`: bedrijfsnaam en introductie.
- `about.html`: informatie over het bedrijf en de werkwijze.
- `contact.html`: duidelijk gemarkeerde fictieve contactgegevens.
- `style.css`: gedeelde styling en mobiele layout.

## Versiebeheer

De standaardbranch is `main`. De bouw is in afzonderlijke stappen vastgelegd met de voorvoegsels `Add:` en `Improve:`.

## Bronnen en hulp

Alle bedrijfsinformatie is verzonnen. Codex heeft geholpen met de voorbeeldcode en Git-stappen. De website gebruikt alleen HTML en CSS, zonder JavaScript of PHP.
